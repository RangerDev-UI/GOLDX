# GOLDX — Bold Editorial Gold Market (Cloudflare Workers)

เว็บติดตาม **ทองคำแท่งไทย 96.5%** และทองคำโลก XAU/USD ในรูปแบบ Bold Editorial Dashboard ใช้เฉพาะข้อมูลที่ได้รับจากแหล่งข้อมูลภายนอกจริง ไม่สร้างราคาหรือประวัติสมมติ

## GOLDX · Bold Editorial หน้าแรก (Production)

ยึดภาพอ้างอิงที่ผู้ใช้เลือก: **GOLDX ขาว–ดำ–แดง นิตยสารการเงิน** มีโลโก้ X สีแดง, หัวข้อราคาทองวันนี้ขนาดใหญ่, ภาพแท่งทองประกอบแบบ SVG, การ์ดทองคำแท่งสีดำ / ทองรูปพรรณสีแดง, Spot Gold / USD-THB สีขาว และกราฟย้อนหลังสีแดง

- **ยังใช้ระบบราคาเดิม**: `/api/market?mode=quotes` ของ GOLDX ดึงจากแหล่งเดิม ไม่ฝังตัวเลขตัวอย่างใดในหน้า Production
- **ทองไทย 96.5%**: รับซื้อ/ขายออกครบสองประเภท พร้อมส่วนต่างราคาสด และเปรียบเทียบวันประกาศก่อนหน้าด้วย `/api/market?mode=previous-thai&before=...` เฉพาะเมื่อมีประวัติที่ยืนยันได้; ไม่มีข้อมูลจะแสดง `—` หรือแจ้งสถานะ
- **หัวข้อขึ้น/ลง** เปลี่ยนเฉพาะเมื่อมีราคาขายออกปัจจุบันและราคาวันก่อนหน้าที่ตรวจสอบได้ ไม่เอาคำว่า "ปรับขึ้น" ไปแสดงตายตัว
- **ทองโลก XAU/USD**: ราคา USD ต่อทรอยออนซ์พร้อมราคา/กรัม และเวลาแหล่งข้อมูล; ไม่แสดงเปอร์เซ็นต์วันก่อนหน้าหาก API ไม่ส่งราคาปิดเปรียบเทียบ
- **USD/THB**: อัตราจาก gateway ปัจจุบัน พร้อมแยกเป็นข้อมูลอ้างอิงรายวันเมื่อแหล่งเป็น Frankfurter
- **กราฟย้อนหลังหน้าแรก**: ใช้ `/api/market?mode=chart&market=thai&period=1W|1M|3M|1Y` แสดงเฉพาะราคาที่บันทึกจากต้นทางและมี timestamp, อนุญาตให้เลือก 7 วัน/30 วัน/3 เดือน/1 ปี, ไม่มีข้อมูลแสดงสถานะว่าง; ไม่จำลองกราฟ
- **หน้าราคาย้อนหลัง**: `/history.html` ยังคงอยู่ และใช้ API Chart เดิมสำหรับกราฟไทยและ XAU/USD พร้อมตาราง
- **ลบหน้าเครื่องมือ 3 หน้า** ตามคำขอ: `calculator.html`, `my-gold.html`, `compare.html` และนำออกจากเมนู/Cloudflare Assets/PWA. ข้อมูลพอร์ตที่เคยเก็บใน localStorage บนอุปกรณ์ของผู้ใช้จะไม่ถูกแตะโดยการ Deploy
- **ไม่มีค่าใช้จ่ายเพิ่ม**: HTML, CSS, JS, inline SVG, Cloudflare Free / APIs เดิม ไม่มี TradingView หรือค่าบริการ AI API

ความใหม่ของราคาและความใหม่ของหน้าเว็บเป็นคนละเรื่องกัน: เว็บเช็กราคาทุก 60 วินาทีเมื่อเปิดหน้าอยู่ และใช้ timestamp แหล่งข้อมูลเพื่อแจ้งกรณีล่าช้า

## Ivory Ledger — XAU/USD ด้านบน (ยืนยันดีไซน์จากพรีวิว)
- **หน้าแรก:** หัวข้อเหลือ “ราคาทองคำ” เพียงบรรทัดเดียว ไม่แสดงวลี “ที่ดูแล้วเข้าใจทันที”
- **ลำดับใหม่:** USD/THB ที่หัวเว็บ → แถบ XAU/USD Spot เต็มความกว้าง → ทองคำแท่ง/ทองรูปพรรณ 96.5% แบบ 2 คอลัมน์บนเดสก์ท็อปและ 1 คอลัมน์บนมือถือ
- **ข้อมูลคงเดิม:** ราคา XAU/USD และต่อกรัมจาก API, ทองไทยทั้ง 4 ช่องรับซื้อ/ขายออก, ส่วนต่างและราคาจริงของวันก่อนพร้อมที่มา, สถานะ API และเวลาอ้างอิง
- **ต้นแบบ:** ยึดพรีวิว `goldx_ivory_world_top_preview.html` แต่ไม่ส่งตัวเลขตัวอย่างขึ้น Production
- **โครงสร้าง:** เปลี่ยนเฉพาะ HTML/CSS และชุดทดสอบ ไม่แตะการคำนวณหรือแหล่งข้อมูลราคา รวมถึงไม่ใช้ TradingView

## ทองคำแท่งและทองรูปพรรณ — เทียบกับวันก่อนหน้า
- **การ์ดราคา:** แยกทองคำแท่ง 96.5% และทองรูปพรรณ 96.5% เป็นคนละการ์ด แต่ละการ์ดแสดงราคาขายออกและราคารับซื้อครบ พร้อมหน่วยบาทต่อ 1 บาททองคำ
- **เปรียบเทียบวันก่อน:** แสดงผลต่างของทั้ง 4 ช่องระหว่างประกาศปัจจุบันกับราคาปิดของวันประกาศก่อนหน้า พร้อมวันที่จริงที่ใช้เปรียบเทียบ; บวก = เพิ่ม, ลบ = ลด, ศูนย์ = เท่าเดิม
- **ข้อมูลย้อนหลัง:** `GET /api/market?mode=previous-thai&before=YYYY-MM-DD` ใน Worker API เดิม ใช้ประวัติของสมาคมค้าทองคำเมื่อมีโทเคนที่อนุญาต หรือรายการประกาศย้อนหลังของ Rakhagold ที่ระบุ `source=gta` และตรวจเวลาประกาศจริง
- **ข้อจำกัด:** หากวันตามปฏิทินก่อนหน้าไม่มีประกาศที่ผ่านการตรวจสอบ ระบบแสดง `—` ไม่อนุมานราคาหรือเทียบกับการปรับขึ้นลงระหว่างวัน; หากมีโทเคน API ทางการ อาจใช้วันประกาศก่อนหน้าที่ใกล้ที่สุดและระบุวันที่
- **รอบอัปเดต:** ราคาปัจจุบันตรวจทุก 60 วินาทีขณะที่หน้าจอเปิดอยู่ ส่วนข้อมูลย้อนหลังตรวจไม่ถี่กว่า 30 นาที โดย CDN Cache 1800 วินาที; กด Refresh จะไม่ทำให้ฝั่งย้อนหลังเรียกถี่โดยไม่จำเป็น
- **ความเป็นส่วนตัวและค่าใช้จ่าย:** ไม่สร้างบัญชี ไม่มีบริการชำระเงินเพิ่ม ไม่ใช้ TradingView

- **หน้าปัจจุบัน:** ธีมขาวครีม–ทองแบบ Editorial ไม่มี Sidebar ตามต้นแบบที่ผู้ใช้เลือก

## GOLDX 4.0 — Aurum Terminal (ฟรี ไม่ใช้ไลบรารีกราฟภายนอก)
- **หน้าแรกใหม่:** จัดหน้าแบบ Aurum Compact ให้เหลือหัวเรื่องสั้น + ราคาทองไทย/XAU/USD + USD/THB/ทองรูปพรรณ + กราฟ/เทคนิค + สรุปวัน ไม่แสดง Hero เดิมอีกต่อไป
- **กราฟ:** ใช้กราฟ SVG ที่เขียนเองเหมือนเดิม รองรับกราฟเส้น/แท่งเทียนเมื่อมี OHLC จริง, RSI/MACD และ EMA โดยทุกช่อง EMA ไม่ติ๊กเมื่อเปิดหน้าเว็บ
- **Data Health:** ยุบเป็นแถบ API ที่ด้านบน กดเปิดดูแหล่งข้อมูลและความใหม่ได้ ไม่ใช้พื้นที่การ์ดใหญ่
- **Market Brief:** ยุบเป็นแถบข้อความสรุปใต้กราฟ กดขยายอ่าน RSI/EMA/Pivot ตามกฎได้ ไม่ใช้ AI API เสียเงิน
- **Gold Factors:** นำการ์ดซ้ำออกทั้งหมด ตัวเลขราคาและ FX ยังคงอยู่ในส่วนราคาต้นหน้า
- **ปฏิทินเศรษฐกิจ:** ย้ายลิงก์ FOMC (Federal Reserve) และ CPI/NFP (BLS) ไปในเมนูข้อมูลเพิ่มเติม โดยไม่ดึงข้อมูลโดยไม่ได้รับอนุญาต
- **ตลาดเริ่มต้น:** ย้ายเมนูเลือกค่าเริ่มต้นไปในแผงข้อมูลเพิ่มเติม คง localStorage ในเบราว์เซอร์
- **ส่วนยุบเพิ่มเติม:** แสดงสรุปราคาไทยของวันนี้เฉพาะการเปลี่ยนแปลง/สูงสุด/ต่ำสุด ไม่ซ้ำราคาขายออก; ย้าย Gold/Silver Ratio และกรอบ ±ATR เข้าข้อมูลเพิ่มเติม (เปิด ATR ในแผงย่อย); ปฏิทินราคาทองย้อนหลัง เครื่องคำนวณ และแจ้งเตือนราคาอยู่ในแถบพับที่เมนูด้านซ้ายเปิดให้ได้อัตโนมัติ
- **PWA:** มี manifest และ service worker สำหรับแคชเฉพาะไฟล์หน้าตาเว็บ ไม่แคช /api หรือราคาทอง ออฟไลน์จึงไม่ใช่โหมดเช็กราคา
- **ค่าใช้จ่าย:** ไม่เพิ่มบริการเสียเงินหรือ API key ใหม่จากการอัปเกรดนี้ แต่ยังขึ้นกับโควตาและนโยบายของ Cloudflare Free รวมถึงเงื่อนไขแหล่งราคาที่มีอยู่เดิม

## GOLDX 3.0
1. **ราคาและ Daily Gold Pulse:** ราคาขายออกล่าสุดและรอบประกาศ; ถ้าข้อมูลประกาศรายรอบของ *วันเดียวกันตามเขตเวลาไทย* มีอย่างน้อย 2 จุด จะคำนวณการเปลี่ยนจากประกาศแรก สูงสุดและต่ำสุดที่แหล่งข้อมูลส่งมา ไม่อ้างว่าเป็น high/low ครบทั้งตลาด
2. **กราฟราคาไทยและโลก:** กราฟเส้น/แท่งเทียน (เมื่อ OHLC ครบ) ช่วงเวลา 1D, 1W, 1M, 3M, 1Y พร้อมการส่งออก CSV
3. **อินดิเคเตอร์:** เส้น EMA 20/50/200 บนกราฟราคา, RSI(14) และ MACD(12,26,9) แบบกราฟย่อย; แสดง — เมื่อข้อมูลไม่ครบจำนวนแท่งที่คำนวณได้
4. **ปฏิทินและตารางทองไทย:** ดึง `/api/market?mode=chart&market=thai&period=1Y` เมื่อเลื่อนมาถึงส่วนนี้ แสดงวันในเดือนและ OHLC ของรายการ `quality=reported-daily-ohlc` เท่านั้น เลือกวันและเปลี่ยนหน้าในตารางได้
5. **ฟีเจอร์เดิม:** กราฟแนวรับ–แนวต้าน Pivot, RSI/EMA/ATR พื้นฐาน, เครื่องคำนวณทอง และแจ้งเตือนเมื่อ *เปิดหน้านี้อยู่* ยังทำงานเหมือนเดิม

6. **ระดับใกล้ราคาอ้างอิงจาก OHLC ย้อนหลัง:** แยกจาก Classic Pivot วันก่อนอย่างชัดเจน แสดงจุดต่ำย้อนหลังที่ต่ำกว่าราคาปัจจุบันสูงสุด 2 ระดับ และจุดสูงย้อนหลังที่เหนือราคาปัจจุบันสูงสุด 2 ระดับ พร้อมวันที่และระยะห่าง คัดจากแท่งรายวันที่ปิดแล้วในช่วงย้อนหลังสูงสุด 180 วันหรือ 120 แท่ง และป้องกันข้อมูลเก่าเกิน 14 วัน หากไม่มีจุดต่ำในช่วงนี้ไม่สร้างแนวรับใหม่ขึ้นเอง; แสดง S1/S2 เดิมว่า "หลุดแล้ว" เมื่อราคาต่ำกว่า Classic Pivot นั้น

## Auto Refresh และการตรวจสอบข้อมูล
- **ราคาทองไทย/ทองโลก และ USD/THB:** ตรวจทุก 60 วินาทีเมื่อแท็บเว็บไซต์เปิดอยู่ (ตามข้อจำกัด Cache และความล่าช้าของต้นทาง)
- **กราฟที่เลือกอยู่:** 1D ตรวจทุก 60 วินาที, 1W ทุก 2 นาที, 1M/3M/1Y ทุก 5 นาที หากต้นทางไม่มีข้อมูลใหม่ ค่ายังคงเดิม และจะแสดงเวลาที่ตรวจกราฟล่าสุดแยกจากเวลาในข้อมูล
- **RSI / MACD / EMA:** คำนวณใหม่จากข้อมูลจริงเมื่อกราฟโหลดสำเร็จ โดยช่อง EMA ทั้งสามไม่ถูกติ๊กอัตโนมัติ
- **Classic Pivot และระดับราคาจาก OHLC:** ทบทวนข้อมูลวันก่อนทุก 6 นาที สถานะหลุด S1/S2 ติดตามราคาที่ตรวจล่าสุด ไม่คำนวณ Pivot ใหม่จากทุก tick
- **สรุปราคาทองวันนี้:** ตรวจทุก 5 นาที
- **ปฏิทินและตารางย้อนหลัง:** โหลดเมื่อเลื่อนมาถึงส่วนนี้ครั้งแรก แล้วตรวจซ้ำทุก 30 นาทีเมื่อเปิดหน้าเว็บ; ผู้ใช้กด “อัปเดตข้อมูล” ได้โดยไม่รีโหลดทั้งหน้า ระบบพยายามคงเดือน/วันที่เลือกไว้
- **ปุ่มรีเฟรชบนสุด:** ตรวจราคา กราฟ เทคนิค สรุปรายวันและปฏิทิน (หากเคยเปิดแล้ว) พร้อมกันตามความเหมาะสม; ปุ่มโหลดกราฟจะอัปเดตเฉพาะกราฟ
- **แท็บที่ไม่ได้เปิดดู:** พักการตรวจอัตโนมัติเพื่อลดปริมาณ API เมื่อกลับมาจะแสดงเวลาเช็กที่ถูกต้อง

**ข้อจำกัด:** Auto Refresh ไม่ใช่ราคา Streaming/WebSocket; ผู้ให้บริการอาจมี Cache หรือประกาศช้า และระบบไม่สร้างราคาจำลองเมื่อข้อมูลขาดหาย การแจ้งเตือนราคายังทำงานเฉพาะขณะเปิดหน้าเว็บอยู่

## โครงสร้าง
- `index.html`: layout และโค้ดฟีเจอร์เดิม (ไม่มีขั้นตอน build frontend)
- `goldx-pro.css`: สไตล์ใหม่ responsive สำหรับ Daily Pulse, indicator, calendar และ history table
- `goldx-pro.js`: การแสดงผลฟีเจอร์ใหม่และการเชื่อม API เดิม
- `goldx-indicators.js`: ฟังก์ชันคำนวณ EMA, RSI แบบ Wilder, MACD บนราคาจริง
- `goldx-levels.js`: ฟังก์ชันคัดเลือกระดับราคาใกล้สุดจากจุดสูง/ต่ำย้อนหลังจริง (ทดสอบแยกได้)
- `goldx-near-ui.js`: แสดงระดับราคาย้อนหลังที่ใกล้ราคาล่าสุดและสถานะการหลุด Pivot
- `worker.js`: Cloudflare Worker, ใช้ logic เดิมใน `netlify/functions/`
- `tests/market.test.cjs`, `tests/indicators.test.cjs`, `tests/levels.test.cjs`: ชุดทดสอบ API และสูตรอินดิเคเตอร์

## ทดสอบ
```bash
node --test tests/*.test.cjs
npx wrangler deploy
```

ทดสอบ endpoint:
- `/api/market?mode=quotes`
- `/api/market?mode=chart&market=thai&period=1D`
- `/api/market?mode=chart&market=thai&period=1Y`
- `/api/market?mode=chart&market=world&period=3M`

**คำเตือน:** ทองคำไทยอาจมีประกาศก่อนหน้า, แหล่งข้อมูลสาธารณะอาจล่าช้า/ไม่ตอบกลับ และทองคำโลกเป็นข้อมูล Spot อ้างอิง ไม่ใช่ราคาซื้อขายที่รับประกันได้ อินดิเคเตอร์เป็นการวิเคราะห์ทางสถิติ ไม่ใช่คำแนะนำลงทุน
